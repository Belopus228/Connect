# Connect — Симулятор электроники ⚡

Android-приложение: виртуальная мастерская электроники на телефоне.

## Что умеет

### 🔌 Макетная плата и пайка
- Перфорированная макетная плата для пайки (шаг 2.54 мм), размеры: 18×12, 24×16, 30×22, 40×28
- Режимы: **Двигать** / **Провод** / **Паять** (дорожка + точки припоя) / **Удалить** / **Нажимать**
- Детали цепляются по сетке отверстий, поворачиваются на 90°, у каждой подписаны пины

### 🧩 Компоненты (каталог)
ESP32 DevKit V1, OLED SSD1306 128×64, TFT ILI9341 2.4", LCD 1602, **nRF24L01**, светодиоды (5 цветов), резисторы (10Ω…10kΩ), тактовые кнопки, батареи 18650 / 9В / Li-Po, зуммер, DHT22, потенциометр, серво SG90, реле 5В, конденсатор, доп. макетная плата.

### 💻 Прошивка ESP32
- Редактор кода + 5 примеров: Blink, Кнопка→LED, OLED, nRF24-передатчик, Светофор
- Загрузка готового `firmware.bin` (размер + SHA-256), виртуальная заливка в стиле esptool: erase → write @0x1000/0x10000 → verify → hard reset
- Интерпретатор выполняет код по кругу (как Arduino `loop()`): `pinMode`, `digitalWrite`, `digitalRead` в `if/else`, `delay`, `Serial.println`, `oled.print/clear`, `nrf.send`, `servo.write`

### ▶ Симуляция цепей
- Расчёт питания: батарея → VIN/3V3 + GND, иначе ESP «не запитан»
- Светодиоды светятся с расчётом тока `(V − 2В) / R`: без резистора — **сгорают** 💥
- Кнопки нажимаются прямо на плате, потенциометр крутится, дисплеи показывают текст прошивки, nRF24 шлёт пакеты в виртуальный эфир, Serial Monitor — во вкладке «Симуляция»

### 📦 Корпус из STL
- Импорт своего `.stl` (бинарный и ASCII, до 25 МБ): 3D-превью с вращением пальцем, треугольники, габариты (мм), объём
- 4 готовых корпуса: 100×70×25, 120×80×35, 60×40×15, круглый Ø80×20
- Расстановка деталей внутри: ползунки X/Y/Z (мм), вид сверху, проверка «влезает / не влезает» по габаритам и высоте

## Сборка APK

APK собирается автоматически в **GitHub Actions** при каждом пуше (`.github/workflows/build-apk.yml`):
JDK 17 + Gradle 8.9 + Android SDK → артефакт `Connect-Electronics-Simulator-APK` (`app-debug.apk`).

Локально (нужен Android SDK):
```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Как пользоваться (быстрый старт)
1. Вкладка **Плата** — уже загружена демо-схема (ESP32 + 18650 + LED с резистором + кнопка + OLED + nRF24, всё припаяно)
2. Вкладка **Код ESP** → «🚀 Залить прошивку в ESP32»
3. Вкладка **Симуляция** — светодиод мигает; на Плате в режиме «👆 Нажимать» нажмите кнопку
4. Вкладка **Корпус** → импорт STL или готовый корпус → расставьте детали ползунками

Требуется Android 7.0+ (API 24).
