# Connect — Симулятор электроники ⚡ (3D)

Android-приложение: виртуальная мастерская электроники на телефоне. **Версия 1.4: реалистичная пайка, исправлено отображение модулей, плюс ПК-версия для Windows.**

## Новое в 1.4
### 🔥 Реалистичная пайка
- Во вкладке «Инструменты» — **паяльник**: температура жала 200–480°C (ползунок) и флюс вкл/выкл
- Каждое новое паяное соединение получает качество по температуре: **блестящий наплыв** (320–380°C + флюс), **холодная пайка** (тусклая, с трещинами — ненадёжна) или **перегрев** (тёмный припой + поджог платы вокруг)
- В 3D на каждом соединении — объёмный купол припоя, янтарный ореол флюса, блик у хорошей пайки, трещины у холодной и подпалина у перегретой; то же в 2D
- При запуске симуляции приложение предупреждает о холодных/перегретых соединениях и советует перепаять
### 🛠 Исправлено отображение модулей
- Модуль при повороте детали теперь поворачивается **целиком** (раньше плата поворачивалась, а USB/экран/чип оставались как были)
- Отрисовка слоями (плата → модели → припой → корпус): большая грань платы больше не перекрывает экраны и чипы дальних модулей
### 🖥 ПК-версия (Windows)
- Отдельное приложение в папке `pc/` (Python + Tkinter): та же 3D-плата, перетаскивание деталей мышью, пайка с температурой, ESP-прошивка, TFT 1.8, STL, проекты JSON
- Готовый **Connect-PC.exe** собирает GitHub Actions (`.github/workflows/build-pc.yml`) → `ci-output/pc/Connect-PC.exe`; самому: `pc/build_windows.bat`

## Новое в 1.3
- **Реальные модели вместо «коробочек»**: ESP32 DevKit — плата, серебристый экран WROOM, антенна, micro-USB, кнопки EN/BOOT, гребёнки со штырями; LED — ножки, цилиндрическое тело и полупрозрачный купол; резистор — цилиндр с цветными полосками кода и аксиальными выводами; 18650 — цилиндр; конденсатор и зуммер — цилиндры; потенциометр — вал с ручкой; серво — качалка; nRF24 — чип, кварц и печатная антенна «змейкой»; дисплеи — плата, рамка и стекло экрана
- **Выходы ESP по-настоящему**: золотые штыри по обеим сторонам модели ESP, в режимах пайки подписаны все пины (VIN, GND, D13…D32); **HIGH-выходы светятся зелёным прямо на модели**
- **Сворачиваемое меню**: кнопка «Свернуть ⟩» прячет правую панель — плата на весь экран; вернуть — кнопкой «⟨ ☰ МЕНЮ»
- **Вкладки в меню**: «🧩 Детали» (каталог + на плате), «🛠 Инструменты» (режимы, камера, плата), «🎯 Свойства» (выбранная деталь + **живые выходы ESP32**: HIGH/LOW/IN по каждому пину и ручной переключатель «вкл/выкл»)

## Интерфейс 1.2 (ландшафт)
- Телефон держится **горизонтально** (приложение зафиксировано в landscape)
- Слева — узкая навигация (Плата / Корпус / Код ESP / Симуляция), сверху — статус, 💾 и ▶ ЗАПУСК
- Центр экрана — большая 3D-плата; **справа — тёмная панель**: компоненты, инструменты, вид и камера, выбранная деталь, список «На плате», подсказки
- **Компоненты добавляются перетаскиванием**: зажать карточку детали в правом меню и тащить на плату — деталь встанет точно в точку сброса (точный пересчёт касания лучом 3D-камеры в плоскость платы). Работает и в 3D, и в 2D. Обычное нажатие на карточку — запасной способ (свободное место)
- Под платой — плавающая подсказка текущего режима

## Что умеет

### 🧊 3D-сцена (главное в 1.1)
- Перспективный 3D-рендер: плата — объёмная плита, каждая деталь — 3D-корпус по реальной высоте (мм), ESP — с чипом и антенной, дисплеи — с экраном и живым текстом, светодиоды светятся объёмной «линзой»
- Камера: режим «🎥 Камера» — вращение пальцем, зум щипком, ракурсы Изометрия / Сверху / Спереди / Сбоку
- В 3D работают все режимы: двигать детали (пересчёт экран→плата), паять/провода (дуги в воздухе + точки припоя), удалять, нажимать кнопки и крутить потенциометр в симуляции
- Провода рисуются 3D-дугами, пайка — дорожками по плате; STL-корпус можно показать прямо в 3D-сцене (☑ «Показать STL-корпус в 3D-сцене»), детали и корпус — в одной сцене
- Старый плоский вид сохранён: переключатель «🧊 3D / ▦ 2D»

### 📺 TFT 1.8" ST7735 (новое)
- Дисплей 1.8 дюйма, 128×160, красная плата, SPI-пины: VCC, GND, SCK, SDA (MOSI), RES, DC, CS, BL
- В прошивке: `tft.print("...");`, `tft.clear();` — пример «📺 TFT 1.8 ST7735» во вкладке «Код ESP»
- Текст примера виден на экране дисплея и в 2D, и в 3D; состояние — во вкладке «Симуляция»

### 🔌 Макетная плата и пайка
- Перфорированная макетная плата для пайки (шаг 2.54 мм), размеры: 18×12, 24×16, 30×22, 40×28
- Режимы: **Двигать** / **Провод** / **Паять** (дорожка + точки припоя) / **Удалить** / **Нажимать**
- Детали цепляются по сетке отверстий, поворачиваются на 90°, у каждой подписаны пины

### 🧩 Компоненты (каталог)
ESP32 DevKit V1, OLED SSD1306 128×64, **TFT 1.8" ST7735 128×160**, TFT ILI9341 2.4", LCD 1602, **nRF24L01**, светодиоды (5 цветов), резисторы (10Ω…10kΩ), тактовые кнопки, батареи 18650 / 9В / Li-Po, зуммер, DHT22, потенциометр, серво SG90, реле 5В, конденсатор, доп. макетная плата.

### 💻 Прошивка ESP32
- Редактор кода + 5 примеров: Blink, Кнопка→LED, OLED, nRF24-передатчик, Светофор
- Загрузка готового `firmware.bin` (размер + SHA-256), виртуальная заливка в стиле esptool: erase → write @0x1000/0x10000 → verify → hard reset
- Интерпретатор выполняет код по кругу (как Arduino `loop()`): `pinMode`, `digitalWrite`, `digitalRead` в `if/else`, `delay`, `Serial.println`, `oled.print/clear`, `nrf.send`, `servo.write`

### ▶ Симуляция цепей
- Расчёт питания: батарея → VIN/3V3 + GND, иначе ESP «не запитан»
- Светодиоды светятся с расчётом тока `(V − 2В) / R`: без резистора — **сгорают** 💥
- Кнопки нажимаются прямо на плате, потенциометр крутится, дисплеи показывают текст прошивки, nRF24 шлёт пакеты в виртуальный эфир, Serial Monitor — во вкладке «Симуляция»

### 📦 Корпус из STL
- Импорт своего `.stl` (бинарный и ASCII, до 25 МБ): 3D-превью с вращением пальцем, треугольники, габариты (мм), объём
- 4 готовых корпуса: 100×70×25, 120×80×35, 60×40×15, круглый Ø80×20
- Расстановка деталей внутри: ползунки X/Y/Z (мм), вид сверху, проверка «влезает / не влезает» по габаритам и высоте

## Сборка APK

APK собирается автоматически в **GitHub Actions** при каждом пуше (`.github/workflows/build-apk.yml`):
JDK 17 + Gradle 8.9 + Android SDK → артефакт `Connect-Electronics-Simulator-APK` (`app-debug.apk`).

Локально (нужен Android SDK):
```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Как пользоваться (быстрый старт)
1. Вкладка **Плата** — уже загружена демо-схема (ESP32 + 18650 + LED с резистором + кнопка + OLED + nRF24, всё припаяно)
2. Вкладка **Код ESP** → «🚀 Залить прошивку в ESP32»
3. Вкладка **Симуляция** — светодиод мигает; на Плате в режиме «👆 Нажимать» нажмите кнопку
4. Вкладка **Корпус** → импорт STL или готовый корпус → расставьте детали ползунками

Требуется Android 7.0+ (API 24).
