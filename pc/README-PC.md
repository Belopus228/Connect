# Connect 3D — ПК-версия

Отдельное приложение для компьютера (Windows .exe собирается в GitHub Actions, см. `ci-output/pc/Connect-PC.exe`).

## Запуск из исходника
```bash
python ConnectPC.py        # Windows
python3 ConnectPC.py       # Linux (нужен python3-tk)
```

## Сборка .exe самому
- Windows: запустить `build_windows.bat` → `dist/Connect-PC.exe`
- Linux: `./build_linux.sh` → `dist/Connect-PC`

## Что умеет
- Изометрическая 3D-плата, реалистичные модели (ESP32 с USB/кнопками/экраном WROOM, LED-купол, резистор с полосками, 18650…)
- Детали **перетаскиваются мышью** из правого меню (или клик по детали → клик по плате), меню сворачивается кнопкой сверху
- Вкладки в меню: «Детали», «Инструменты» (режимы, **паяльник 200–480°C + флюс = качество пайки**, камера, выходы ESP), «Код ESP»
- Реалистичная пайка: блестящая / холодная (трещины) / перегрев (поджог), предупреждения при запуске
- ESP32: прошивка с примерами (включая **TFT 1.8" ST7735**), живые выходы HIGH/LOW, ручное переключение пинов
- OLED/TFT/LCD, nRF24L01, кнопки, потенциометр, расчёт тока LED (сгорит без резистора)
- Импорт STL-корпуса (каркас поверх платы), сохранение/открытие проектов JSON
